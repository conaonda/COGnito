# COGnito v1.0 로드맵

## 비전

COG URL을 직접 입력하는 단순 뷰어에서, **공개 COG 영상을 자동 수집·탐색·공유할 수 있는 플랫폼**으로 진화한다.

## 현재 상태 (v0.2.6)

STAC 연동·카탈로그 고도화·메타데이터 구조화까지 완성된 상태.

- WebGLTile + ImageCanvas 이중 렌더링 파이프라인
- Affine + Reproject 이중 투영 모드
- 밴드 자동 감지 (RGB/Grayscale)
- 모바일 최적화 (품질 토글)
- Playwright 성능 테스트 8종
- CI/CD (GitHub Pages 자동 배포, PR 프리뷰)
- Supabase Auth (이메일/Google OAuth)
- 수동 COG 등록 + 카탈로그 브라우징 UI (검색, 페이지네이션)
- 뷰어 동적 메타데이터 (카탈로그/URL 기반)
- STAC API 클라이언트 (Earth Search, Planetary Computer)
- STAC 검색 → COG 메타데이터 자동 추출 → 등록
- 영상 메타데이터 구조화 (촬영일자, 지역, 센서)
- 해시태그 기능 (입력, 저장, 필터링)
- 썸네일 자동 생성
- 제목/설명 자동 생성
- STAC 공간 검색 상세화 (포함/교차 옵션)
- s3:// 프로토콜 URL 자동 변환
- Planetary Computer SAS 토큰 서명
- CORS 프록시 Worker

## 아키텍처 결정

| 결정 | 선택 | 근거 |
|------|------|------|
| 백엔드 | Supabase (BaaS) | 서버 코드 최소화. Auth/DB/Storage 통합. 오픈소스. |
| 인증 | GitHub·Google OAuth | 별도 회원가입 불필요. Supabase Auth 기본 지원. |
| COG 수집 | STAC 자동 + 수동 등록 | STAC은 표준 API로 확장성 확보, 수동 등록은 유연성 확보. |
| 프론트엔드 | 기존 Vite + OpenLayers 유지 | 안정적인 기존 뷰어 위에 기능 확장. |

## 콘텐츠 철학

**"포맷이 맞으면 수집"이 아니라 "사람들과 나눌 가치가 있는 영상"을 수집한다.**

COGnito에 등록되는 영상은 기술적으로 렌더링 가능한지가 아니라, *의미*가 있는지를 기준으로 선별한다.

- 영상 하나하나에는 제목, 배경 설명, 촬영 맥락이 따라붙어야 한다.
- "이게 왜 흥미로운가?"에 답할 수 없는 영상은 등록하지 않는다.
- STAC 자동 수집이라도 맹목적인 bulk import는 하지 않는다. 수집 기준은 항상 "사람에게 보여줄 만한가?"이다.

이 원칙은 카탈로그 설계와 이후 모든 콘텐츠 수집 작업에 적용된다.

### v0.2.0 — BaaS 인프라 + 인증 + 기본 카탈로그 ✅

Supabase 연동, 소셜 로그인, 수동 COG 등록 및 카탈로그 기본 기능.

**스코프 (완료):**

- Supabase 프로젝트 설정 (DB, Auth, Storage)
- GitHub/Google OAuth 소셜 로그인
- 로그인/로그아웃 UI (헤더 영역)
- DB 스키마 설계 및 마이그레이션
- 수동 COG URL 등록 폼 (URL 입력 → 메타데이터 자동 파싱 → DB 저장)
- 영상별 제목·설명 입력
- 카탈로그 브라우징 UI (검색, 페이지네이션)
- 뷰어 동적 메타데이터 (Harvey 하드코딩 제거)

**DB 스키마:**

```
profiles
  id, provider, display_name, avatar_url, created_at

cog_images
  id, url, title, description, source_type (stac|manual),
  crs, bands, bbox, thumbnail_url, metadata_json,
  captured_at, region, sensor, resolution, tags,
  created_at

likes
  user_id, cog_image_id, created_at

watchlists
  id, user_id, name, created_at

watchlist_items
  watchlist_id, cog_image_id, added_at
```

### v0.4.0 — 소셜 기능 + 공유

좋아요·관심 목록·공유로 사용자 참여와 재방문을 유도한다.

**스코프:**

- 좋아요(Like) 토글 (로그인 필수)
- 관심 목록(Watchlist) CRUD (생성, 이미지 추가/제거, 삭제)
- 인기순/최신순 정렬
- 공유 URL 생성 (뷰 상태 인코딩: COG URL, 중심 좌표, 줌 레벨) (#55)
- 딥 링크 지원 (공유 URL로 접근 시 동일 뷰 복원)

**검증 기준:**
- 로그인 → COG 좋아요 → 좋아요 수 반영 → 인기순 정렬 반영
- 관심 목록 생성 → 이미지 추가 → 목록에서 조회 → 클릭으로 뷰어 이동
- 공유 URL 복사 → 새 탭에서 열기 → 동일 뷰 상태 복원

- Min/Max 슬라이더 조작 → 실시간 렌더링 업데이트
