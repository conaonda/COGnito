# COGnito 사용자 가이드

COGnito는 웹 브라우저에서 Cloud Optimized GeoTIFF(COG) 영상을 탐색하고 공유할 수 있는 뷰어입니다.

---

## 1. COG 영상 보기

1. 상단 URL 입력란에 COG 파일의 URL을 입력합니다.
2. **로드** 버튼을 클릭하거나 Enter를 누릅니다.
3. 영상이 지도 위에 표시되며 자동으로 해당 영역으로 이동합니다.

기본 영상(Hurricane Harvey SkySat)이 자동으로 로드됩니다.

### Min/Max 스트레치

우측의 **⚙** 버튼을 클릭하면 뷰어 컨트롤 패널이 열립니다. **Min/Max 슬라이더**를 조정하여 영상의 밝기 범위를 변경할 수 있습니다.

- 슬라이더를 드래그하거나 옆의 숫자 입력란에 직접 값을 입력할 수 있습니다.
- Min 값이 Max 값을 초과하면 자동으로 보정됩니다.
- **자동** 버튼을 클릭하면 원래 통계값으로 초기화됩니다.
- RGB 모드에서는 일괄/개별 스트레치를 선택할 수 있습니다.

---

## 2. 지도 조작

- **팬**: 마우스 드래그 또는 터치 드래그
- **줌**: 마우스 휠 또는 핀치 줌
- **내 위치로 이동**: 지도 우측의 **◎** 버튼을 클릭하면 브라우저 Geolocation을 통해 현재 GPS 위치로 지도가 이동합니다. 위치 권한이 필요하며, 거부 시 안내 메시지가 표시됩니다.
- **좌표 확인**: 우측 하단에 마우스 위치의 지도 좌표와 경위도가 표시됩니다.
- **줌 레벨 표시**: 좌표 패널 하단에 현재 줌 레벨이 표시되며, 줌 변경 시 실시간으로 갱신됩니다.

좌측 하단의 **영상 정보** 패널에서 현재 로드된 영상의 CRS, 밴드, 해상도 등을 확인할 수 있습니다.

---

## 3. 영상 공유

1. 보고 싶은 위치/줌으로 지도를 이동합니다.
2. **공유** 버튼을 클릭합니다.
3. 현재 뷰 상태(COG URL, 중심 좌표, 줌 레벨)가 포함된 URL이 클립보드에 복사됩니다.
4. 이 URL을 다른 사람에게 전달하면 동일한 뷰를 볼 수 있습니다.

---

## 4. 카탈로그

등록된 영상을 탐색하려면:

1. 좌측의 **☰** 버튼을 클릭하여 카탈로그 패널을 엽니다.
2. 검색란에 키워드를 입력하여 제목/설명으로 검색합니다.
3. 태그, 센서, 지역 필터로 결과를 좁힐 수 있습니다.
4. **등록 출처** 필터 드롭다운에서 **전체**, **STAC 자동**, **수동 등록**을 선택하여 등록 방식별로 결과를 필터링할 수 있습니다.
5. 카드를 클릭하면 해당 영상이 뷰어에 로드됩니다.
6. 현재 뷰어에 로드된 영상의 카드는 강조 표시(파란색 테두리)되어 쉽게 식별할 수 있습니다.

각 카탈로그 카드에는 등록 출처를 나타내는 배지가 표시됩니다:
- **STAC** (파란색): STAC API를 통해 자동 등록된 영상
- **수동** (초록색): 직접 URL을 입력하여 수동 등록한 영상

### 영상 등록

로그인 상태에서 COG가 로드되어 있으면 **등록** 버튼이 표시됩니다.

1. **등록** 버튼을 클릭합니다.
2. 제목, 설명, 촬영일시, 지역, 센서, 태그를 입력합니다 (제목/설명은 자동 생성됨).
3. **등록** 버튼으로 카탈로그에 저장합니다.

### 내 등록 영상만 보기

로그인 상태에서 카탈로그 패널 상단의 **내 등록 영상만** 체크박스를 선택하면 내가 직접 등록한 영상만 필터링하여 볼 수 있습니다.

- 비로그인 상태에서는 체크박스가 표시되지 않습니다.
- 로그아웃 시 필터가 자동으로 해제됩니다.
- 다른 검색/출처/정렬 필터와 함께 사용할 수 있습니다.

### 메타데이터 편집

로그인 상태에서 본인이 등록한 영상의 카드에는 **✎ 편집** 버튼이 표시됩니다.

1. **✎ 편집** 버튼을 클릭하면 편집 모달이 열립니다.
2. 제목과 설명을 수정합니다.
3. **저장** 버튼을 클릭하면 변경사항이 저장되고 카드 목록이 즉시 갱신됩니다.
4. **취소** 버튼 또는 모달 바깥 영역을 클릭하면 변경사항 없이 닫힙니다.

### 영상 삭제

로그인 상태에서 본인이 등록한 영상의 카드에는 **🗑 삭제** 버튼이 표시됩니다.

1. **🗑 삭제** 버튼을 클릭하면 삭제 확인 모달이 열립니다.
2. 모달에 영상 제목이 표시되어 삭제 대상을 확인할 수 있습니다.
3. **삭제** 버튼을 클릭하면 영상이 영구 삭제되고 카드 목록이 즉시 갱신됩니다.
4. **취소** 버튼 또는 모달 바깥 영역을 클릭하면 삭제 없이 닫힙니다.
5. 삭제 실패 시 모달 내부에 오류 메시지가 표시됩니다.

### 태그 클릭 필터

카탈로그 카드에 표시된 태그를 클릭하면 해당 태그가 태그 필터 입력란에 자동으로 설정되고 즉시 필터링이 적용됩니다.

- 태그를 클릭해도 카드 뷰어(영상 로드)는 열리지 않고 필터만 적용됩니다.
- 다른 검색/정렬 필터와 함께 사용할 수 있습니다.

### 촬영 연도 필터

카탈로그 패널의 **촬영 연도** 드롭다운에서 특정 연도를 선택하면 해당 연도에 촬영(`captured_at` 기준)된 영상만 필터링됩니다. 기본값은 **전체**로, 모든 연도의 영상이 표시됩니다.

- 드롭다운에는 현재 연도부터 최근 6년(총 7개 옵션)이 제공됩니다.
- 다른 검색/정렬 필터와 함께 사용할 수 있습니다.
- **필터 초기화** 버튼으로 연도 필터도 함께 초기화할 수 있습니다.

### 활성 필터 칩

필터가 적용된 상태에서 카탈로그 패널에 활성 필터 조건이 **칩(chip)** 형태로 표시됩니다. 각 칩의 **×** 버튼을 클릭하면 해당 필터만 개별적으로 해제됩니다.

- 지원 필터: 검색어, 출처, 태그, 촬영 연도, 내 등록 영상만, 좋아요한 영상만
- 활성 필터가 없으면 칩 영역이 표시되지 않습니다.
- **필터 초기화** 버튼으로 모든 칩을 한 번에 제거할 수도 있습니다.
- 스크린 리더 접근성을 지원합니다 (ARIA 속성 적용).

### 필터 일괄 초기화

카탈로그 패널 상단에 **필터 초기화** 버튼이 표시됩니다. 이 버튼을 클릭하면 검색어, 태그, 센서, 지역, 출처, 촬영 연도, 내 영상만 필터를 한 번에 모두 초기화하고 전체 목록을 다시 조회합니다.

- 필터가 하나도 활성화되지 않은 경우 버튼이 표시되지 않습니다.
- 하나 이상의 필터가 적용된 상태에서만 버튼이 나타납니다.

### 카드 메타데이터 표시

카탈로그 카드에는 다음 메타데이터가 표시됩니다:

- **📅 날짜**: 촬영일자(`captured_at`)가 있는 경우 `YYYY-MM-DD` 형식으로 표시
- **📐 해상도**: 해상도(`resolution`) 값이 있는 경우 `{값}m` 형식으로 표시 (없는 경우 표시하지 않음)

### 정렬

카탈로그 패널의 정렬 드롭다운에서 **최신순**, **인기순**(좋아요 수 기준), **조회수순**(조회수 기준), **촬영일자순**(`captured_at` 기준 내림차순, 촬영일자가 없는 영상은 맨 뒤)을 선택할 수 있습니다.

드롭다운 옆의 **↑/↓ 버튼**을 클릭하면 오름차순(↑)과 내림차순(↓)을 전환할 수 있습니다. 정렬 기준을 변경하면 해당 기준의 기본 방향으로 자동 초기화됩니다.

### 검색어 하이라이팅

카탈로그 검색란에 키워드를 입력하면 검색 결과 카드의 **제목**과 **설명**에서 일치하는 부분이 노란색 배경으로 강조 표시됩니다.

- 대소문자 구분 없이 매칭됩니다.
- 검색어를 지우면 강조 표시가 사라지고 원래 텍스트로 돌아옵니다.

### 검색 결과 총 영상 수

카탈로그 패널 상단에 **총 N개 영상** 형태로 현재 검색/필터 조건에 해당하는 영상의 총 수가 표시됩니다.

- 검색어나 필터를 변경하면 총 수가 즉시 갱신됩니다.
- 검색 결과가 없으면 **총 0개 영상**으로 표시됩니다.
- 오류 발생 시 총 수 표시가 숨겨집니다.

### 페이지당 영상 수

카탈로그 패널 하단의 **페이지당** 드롭다운에서 한 페이지에 표시할 영상 수를 **10**, **20**, **50** 중에서 선택할 수 있습니다. 기본값은 20입니다.

- 값을 변경하면 자동으로 첫 페이지로 이동하여 결과가 갱신됩니다.
- 다른 검색/정렬 필터와 함께 사용할 수 있습니다.

### 필터/정렬 상태 URL 공유

카탈로그에서 필터나 정렬을 변경하면 브라우저 URL이 자동으로 업데이트됩니다. 이 URL을 복사해 다른 사람에게 전달하면 동일한 필터/정렬 상태로 카탈로그가 열립니다.

- URL에 반영되는 파라미터: `tag`, `sensor`, `region`, `source`, `year`, `sortBy`, `sortOrder`, `search`, `likedOnly`, `myImagesOnly`
- 기본값(최신순 내림차순, 빈 필터 등)은 URL에서 제거되어 깔끔하게 유지됩니다.
- 페이지를 새로 고침하거나 URL로 직접 접근해도 필터/정렬 상태가 복원됩니다.

### 지도로 이동

bbox(공간 범위) 정보가 있는 카탈로그 카드에는 **🗺️ 지도로 이동** 버튼이 표시됩니다. 클릭하면 해당 영상의 촬영 범위로 지도 뷰가 자동으로 이동합니다.

- bbox 정보가 없는 카드에는 버튼이 표시되지 않습니다.
- 지도 이동은 애니메이션(500ms)으로 부드럽게 처리됩니다.

### 그리드/리스트 뷰 전환

카탈로그 패널 상단의 **⊞ / ≡** 버튼으로 카드 표시 방식을 전환할 수 있습니다.

- **⊞ 그리드 뷰** (기본): 카드가 격자 형태로 표시됩니다.
- **≡ 리스트 뷰**: 썸네일(소형) + 제목/설명/메타데이터가 수평으로 배치되어 한 번에 더 많은 항목을 볼 수 있습니다.
- 선택한 뷰 모드는 localStorage에 저장되어 새로고침 후에도 유지됩니다.
- 기존 카드 기능(클릭, 좋아요, 공유, 관심목록, 태그, hover bbox)은 두 뷰 모두에서 동일하게 동작합니다.

### 카드 hover 시 bbox 하이라이트

카탈로그 카드에 마우스를 올리면 해당 영상의 촬영 영역(bbox)이 지도 위에 반투명 사각형으로 강조 표시됩니다. 마우스를 카드 밖으로 이동하면 하이라이트가 제거됩니다.

- bbox 정보가 없는 영상은 하이라이트가 표시되지 않습니다.

### 카드 키보드 접근성

카탈로그 카드는 키보드만으로도 탐색하고 열 수 있습니다.

- **Tab** 키로 카드 간 포커스를 이동할 수 있습니다.
- 포커스된 카드에서 **Enter** 또는 **Space** 키를 누르면 해당 영상이 뷰어에 로드됩니다.
- 카드 내부의 좋아요, 관심목록, 공유 등 버튼은 독립적으로 Tab 접근이 가능합니다.

### 카드 공유

카탈로그 카드의 **🔗 공유** 버튼을 클릭하면 해당 영상의 뷰어 URL이 클립보드에 복사됩니다. 로그인 여부와 관계없이 모든 사용자에게 표시됩니다.

- 복사된 URL을 다른 사람에게 전달하면 해당 COG 영상이 바로 로드된 상태로 뷰어가 열립니다.
- 복사 성공 시 버튼이 **✅ 복사됨**으로, 실패 시 **❌ 실패**로 2초간 표시됩니다.

### 조회수

카탈로그 카드에는 **👁 N** 형태로 조회수가 표시됩니다. 카드를 클릭하여 영상을 뷰어에 로드하면 조회수가 자동으로 1 증가합니다.

- 조회수는 로그인 여부와 관계없이 모든 사용자에게 표시됩니다.
- 카드를 클릭할 때마다 카운트가 증가합니다.

### 좋아요

로그인 상태에서 카탈로그 카드의 **♥** 버튼을 클릭하면 좋아요를 토글할 수 있습니다. 좋아요 수는 모든 사용자에게 표시됩니다.

### 좋아요한 영상만 보기

로그인 상태에서 카탈로그 패널 상단의 **좋아요한 영상만** 체크박스를 선택하면 내가 좋아요한 영상만 필터링하여 볼 수 있습니다.

- 비로그인 상태에서는 체크박스가 표시되지 않습니다.
- 다른 검색/정렬 필터와 함께 사용할 수 있습니다.
- **필터 초기화** 버튼으로 이 필터도 함께 초기화할 수 있습니다.

### 관심목록

로그인 상태에서 카탈로그 카드의 관심목록 버튼으로 영상을 관심목록에 추가하거나 제거할 수 있습니다.

- **+ 관심목록**: 관심목록에 없는 영상에 표시됩니다. 클릭하면 추가할 관심목록을 선택하는 모달이 열립니다.
- **✓ 관심목록** (보라색 배경): 이미 관심목록에 있는 영상에 표시됩니다. 클릭하면 제거할 관심목록을 선택하는 모달이 열립니다.

1. 좌측의 **관심** 버튼을 클릭하여 관심목록 패널을 엽니다.
2. **+ 새 관심목록** 버튼으로 관심목록을 만듭니다.
3. 관심목록을 열어 저장된 영상을 확인하고, 클릭하면 뷰어에 로드됩니다.

---

## 5. STAC 검색

외부 STAC(Spatio-Temporal Asset Catalog) API에서 위성 영상을 검색하려면:

1. 우측의 **STAC** 버튼을 클릭하여 검색 패널을 엽니다.
2. STAC API를 선택합니다 (Earth Search, Planetary Computer, 또는 커스텀 URL).
3. 컬렉션을 선택합니다 (선택 사항).
4. 검색 조건을 설정합니다:
   - **현재 맵 범위로 검색**: 현재 보고 있는 지도 범위 내 영상만 검색
   - **영역 그리기**: 맵에서 사각형을 그려 특정 영역으로 검색 (AOI)
   - **날짜 범위**: 시작일/종료일 지정
5. **검색** 버튼을 클릭합니다.
6. 결과에서:
   - **뷰어에서 보기**: 해당 COG를 바로 뷰어에 로드
   - **카탈로그에 등록**: 메타데이터가 자동 채워진 상태로 등록 모달 열기

### AOI (관심 영역) 설정

1. **영역 그리기** 버튼을 클릭합니다.
2. 지도에서 마우스로 사각형을 드래그합니다.
3. 파선으로 표시된 영역이 검색 시 `intersects` 파라미터로 사용됩니다.
4. **초기화** 버튼으로 AOI를 삭제할 수 있습니다.

## 6. 로그인

카탈로그 등록 기능을 사용하려면 로그인이 필요합니다.

1. 우측 상단의 **로그인** 버튼을 클릭합니다.
2. 이메일/비밀번호 또는 Google 계정으로 로그인합니다.
3. 로그인 후에도 이전에 보던 영상과 지도 위치가 유지됩니다.

## 7. 모바일 사용

모바일에서는 자동으로 Canvas 렌더링 파이프라인이 사용됩니다.

- 우측 하단의 **저해상도/고해상도** 토글로 영상 품질을 변경할 수 있습니다.
- 고해상도 모드는 데이터 사용량이 증가하므로 Wi-Fi 환경을 권장합니다.

## 9. 지원 형식

- **Cloud Optimized GeoTIFF (COG)**: HTTP/HTTPS로 접근 가능한 COG 파일
- **s3:// URL**: 자동으로 HTTPS URL로 변환됩니다
- **CORS 제한 URL**: Sentinel 등 일부 호스트는 CORS 프록시를 통해 자동 우회됩니다

---

## 10. 오프라인 상태

인터넷 연결이 끊기면 COGnito는 자동으로 오프라인 상태를 감지합니다.

- 화면 상단에 **오프라인** 배너가 표시됩니다.
- 서버 연결이 필요한 버튼(COG 로드, 등록, STAC 검색 등)은 자동으로 비활성화되며, 마우스를 올리면 안내 메시지가 표시됩니다.
- 연결이 복원되면 배너가 사라지고 버튼이 자동으로 활성화됩니다.

---

## 11. 문제 해결

영상이 로드되지 않는 경우:
- URL이 유효한 COG 파일인지 확인하세요.
- CORS 오류가 발생하면 프록시가 지원하는 호스트인지 확인하세요.
- 브라우저 콘솔(F12)에서 상세 오류 메시지를 확인할 수 있습니다.

자세한 기술적 문제 해결은 [troubleshooting.md](./troubleshooting.md)를 참조하세요.
